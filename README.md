#  MoodVerse

MoodVerse is a Full Stack Mood-Based Recommendation Web Application that helps users discover movies, music, books, and quotes based on their current mood.

## 🚀 Live Demo

🌐 Frontend: https://moodverse-ruby.vercel.app

⚙️ Backend: https://moodverse-k02w.onrender.com

---

## ✨ Features

- 🔐 User Authentication (Signup/Login)
- 😊 Mood-Based Recommendations
- ❤️ Add & Remove Favorites
- 📱 Fully Responsive Design
- ☁️ MongoDB Atlas Database
- 🚀 Live Deployment

---

## Tech Stack

### Frontend

- React.js
- Vite
- CSS

### Backend

- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

### Deployment

- Vercel
- Render

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
